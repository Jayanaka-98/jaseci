- **byLLM routes media return types to the dedicated generation endpoints**: `-> Image` on an image model (`dall-e-3`, `gpt-image-1`), `-> Audio` on a speech model (`tts-1`), and `-> Video` on a video model (`sora-2`, Veo) now call `image_generation`, `speech` and `video_generation` instead of raising, and an `Audio` argument returning `str` on a speech-to-text model (`whisper-1`) calls `transcription`. Those endpoints take a flat prompt rather than a chat message list, so byLLM renders one from the function's docstring and argument values without the chat system persona. Video generation is an asynchronous job that byLLM polls to completion, bounded by `poll_interval`/`poll_timeout`; a `def` blocks in the poll and an `async def` awaits it. `Video` gained `from_bytes`/`save` so a generated clip can be written to disk.
